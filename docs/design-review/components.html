Interis component system

This sheet covers every shared piece in components/ui and components/layout, plus the patterns features keep rebuilding by hand. Each one is redrawn with the slate, credits and rocket rules. The table at the end lists which file changes and how.

1 · Tokens

  • Type: four display sizes, three body sizes and two mono roles. Uppercase is only for kickers and slates. Kickers use .12em tracking and slates .08em, replacing the 7 tracking values in use today.
  • Radius: --radius drops from 0.75rem to 3px. The scale becomes fixed values instead of a calc() on it (today rounded-2xl is 20px). Delete the per-theme overrides.

2 · Primitives

  • Buttons: 3px corners and no glow shadows. Press is a 1px shift, not scale(.97). Height is 32px on desktop and 44px on phones. Loading keeps the width and shows three reel ticks instead of a spinner.

Inconsistencies found

  • Three shells, one surface: the --profile/settings/developer-shell-* sets repeat each other. Their muted text is 36% or 30% (both under 4.5:1), and the panel/bio classes are copies. Collapse them into .shell* + .surface.
  • Dead CSS: .theme-nav-pill-active, .theme-segment-*, .theme-menu-item-active, .theme-shell-* classes and --theme-modal-gradient/pattern.
  • Inline kickers: 113 font-mono uppercase tracking-[…] strings with 7 tracking values, and 80 uses of 7–9px text. Hardcoded colours: #ef4444, amber-*, green-500, rose-500, and ::selection{color:#000}, which breaks marquee.
  • Radius and blur: rounded-full ×137, -lg ×84, -xl ×36, plus 44 hand-rolled pill buttons and 9 backdrop-blurs. About 18 "Unknown" fallbacks, and Star icons in 3 files.

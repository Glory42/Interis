6 · Sign in, join, recover

  • Generic split: form left, "Trending Movies/Shows" right, over a blurred poster wall (_authLayout.tsx:41-77).
  • h-9 text-sm inputs (iOS zoom); one error box after submit (RegisterForm.tsx:132); login minLength=8 (LoginForm.tsx:312) fires the browser popup.
  • Register puts autoComplete="username" on the handle (RegisterForm.tsx:70), so password managers save "glory42" while login asks for the email. Reset has no steps and no hidden username (ForgotPasswordForm.tsx:260).
  • Recovery setup uses a plain PageWrapper (setup-security-question.tsx:199) and claims it's the only way to change email (SetupSecurityQuestionForm.tsx:363); email change uses the password.

Admin: from nine tabs to a moderation desk

Today /admin is nine tab panels, each the newest 20 rows. Proposed: six sections (Overview, Reports, Users, Content, Audit log, Cache) plus phone triage. Tags: FRONTEND ONLY NEW ENDPOINT NEW TABLE/MIGRATION. Admin is glory42; everything else is invented and marked ILLUSTRATIVE.

Ground rules every proposal below follows (CLAUDE.md)
Pollingnone · refetch on focus or ↻ Refresh, staleTime 60s
Listsserver default 25 · cursor (created_at, id) for reports + audit
GET handlersread-only · audit rows written only by POST/DELETE
New tables / columnsexplicit index() on every FK and WHERE column
Overview numbersCOUNT(*) via Promise.all, on demand · not a live dashboard
Joins to authors / titlesone inArray() batch + Map, never per row
Destructive actionsre-enter admin password, or type @username to delete

0 · What admin can do today, and what's wrong

  • Can today: list reports by status; resolve, dismiss, or remove the reported review/post (reports.routes.ts:14-19). Search users by username; reset password, suspend (optional reason), unsuspend, promote, demote, delete (admin.routes.ts:14-23). List + delete reviews, diary, posts, lists, activities. List, edit, TMDB-refresh, delete films and series.
  • First 20 rows, ever. The frontend never sends limit/offset (features/admin/api.ts:34,57); report #21 is unreachable.
  • No audit trail. reports.resolvedBy (reports.entity.ts:44) is the only record. Suspend, promote, delete, password reset leave nothing.
  • One row per reporter. Remove content closes only that report (reports.service.ts:74); sibling reports on the deleted review stay pending. Rows carry no author or link (api.ts:9-21).
  • Gaps: comments (reviews.entity.ts:71, posts.entity.ts:54) and lists can't be reported; comments have no admin panel. Search is username-only (admin.repository.ts:21).
  • Account actions are too easy. Admin types the user's new password in plain text (AdminUserRowActions.tsx:69), also on their own row (AdminUsersPanel.tsx:85), never re-entering their own password: a hijacked admin session can take over any account. Promote is one click. Suspensions have no expiry or "by", and the reason is never shown again (api.ts:24-29).
  • No URL state (AdminDashboardPage.tsx:26): refresh resets to Reports, nothing is linkable. Generic look: rounded-full pills (AdminReportsPanel.tsx:123), cards, icon nav.

1 · Console shell and Overview

  • Overview is one credits block from GET /api/admin/overview: ~8 COUNT(*) in Promise.all, run on open or ↻ only; the slate says when. If slow, memoise 5 min in process memory, never a timer or a write. NEW ENDPOINT

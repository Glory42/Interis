Logging and reviewing: desktop and phone browser

One form with every field the current LogMediaDialog has: watch date, rewatch, rocket rating, review (5,000 characters), like, contains spoilers, and delete when editing. Only the layout changes between desktop and phone.

1 · Desktop: modal

  • The header is a slate showing what you're logging (LOG · FILM · 2026) instead of the generic "Write a Review". The accent border still follows movie or TV.
  • Date and rewatch become one sentence: "Watched today, Nov 6 · first watch". Tapping the date opens the calendar, and tapping "first watch" switches it to "rewatch". It replaces the two separate boxes and matches the filter sentences.
  • The rocket launch track and like sit on one line. The review box gets most of the space. Spoilers is a small switch under the review instead of a big red box that's always visible.
  • The save button changes with what you've entered: Save log with no text, Post review once you write something. Delete is a quiet text link, and only appears when editing.

Episode or season reviews use the same modal: the slate reads REVIEW · S00 · E04, and the date sentence becomes "Watched ✓". Delete only shows when editing an existing log.

2 · Phone browser: full screen

  • Full screen, not a bottom sheet. A sheet plus the on-screen keyboard leaves almost no room to write. Use 100dvh so the browser's address bar doesn't push the layout around.
  • Cancel and Save at the top, like a native compose screen. They stay reachable while the keyboard covers the bottom half.
  • While you type, a slim bar sits just above the keyboard with the spoilers switch and character count, positioned with visualViewport so it follows the keyboard in iOS Safari and Chrome.
  • The date opens the phone's built-in date picker (<input type="date">), which is faster and more familiar on a phone than a custom calendar.
  • Draft text is saved locally, so switching apps or a browser reload doesn't lose a half-written review.

Interis design review

I reviewed the running app (landing, movie detail, archive, public profile) in the default theme and checked the components behind them. The base is solid: the theme token system, consistent surface cards and real poster art. Most of what holds it back is typography (monospace and tiny uppercase labels nearly everywhere), copy that reads like dev notes, and empty states that show placeholders instead of hiding them. Each card shows the current version on the left and my proposal on the right.

01 Typography: give monospace one job P1

  • Titles (MediaDetailsMainSection, MediaArchivePage h2, PageWrapper h1), cast chips, review text and empty states all use font-mono. The theme already defines --theme-display-font (Space Grotesk), but mono overrides it.
  • text-[9px]–[11px] plus uppercase plus tracking-[0.18em] is the default label style. At 9–10px with 0.18em tracking, labels like "COMMUNITY" or "RATING BREAKDOWN" are hard to read.
  • Rule: Display font for titles, Sora for body text, and mono only for numbers, dates and short metadata. Labels should be at least 11px, with uppercase reserved for one- or two-word kickers.

02 Navbar: plain language, less shouting P2

  • "MOVIE" and "SERIAL" are singular and all-caps, and "Serial" isn't how English speakers refer to TV. Use "Films" and "TV" (or "Shows", which the landing page already uses: "Trending Shows").
  • LOGIN and REGISTER are also all-caps mono. "Sign in" plus one filled "Create account" button is enough.
  • On desktop the search field is only 160px wide and reads "search...". Give it a ⌘K hint so it works as the primary entry point.

03 Movie page: one primary action, quick toggles below it P1

  • MediaActionsSidebar uses a 2×2 grid of equal pill buttons. "LOGIN TO LOG" wraps onto two lines inside a pill (screenshot at 1280px), and Log, Queue, Watch and Like all carry the same visual weight.
  • Logging is the core action of the app, so make it a full-width primary button. Watched, Like and Watchlist become an icon toggle row (Letterboxd users expect this), with the rocket rating directly under it (see the signed-in review for the horizontal launch track).
  • Guests see four buttons that all link to /login. Replace them with one card: "Sign in to log, rate and review."

04 Don't show what you don't know P2

  • MovieDetailsMainSection.tsx:38-70 falls back to "Unknown" for runtime, language, country and director. The facts grid then renders "Box Office: Unknow…" truncated, and the director appears a second time after the title.
  • With 0 logs, RatingBreakdownChart draws 10 flat bars that look like a loading glitch.
  • Community score "-- 0 logs" in large pink mono looks like an error.
  • Rule: filter out unknown facts. When a section has no data, show one sentence with a call to action, or hide the section entirely.

05 Profile: make the person the focus, not the placeholders P3

  • Visitors see "No bio yet." (ProfileHeaderCompact.tsx:128) and the invented location "Unknown Galaxy" (:82). Hide both when they're empty, and show an "Add a bio" link only to the owner.
  • The Follow button is a 20px-tall outlined mono label that looks disabled. It's the main thing a visitor would click, so make it a filled primary button.
  • Eight "Not set" favourite slots take up most of the screen. For visitors, hide the row when it's empty. For the owner, collapse it to one prompt: "Pick your top 4".
  • Stats sit far to the right, away from the name. Move them into the identity block as an inline line of text.
